# 每日与每周节奏

这不是需要连续打卡的习惯系统。它只负责让重要内容不在 Inbox 和项目里失去后续。

## 每天三分钟

1. 从首页点击[写今天](obsidian://daily)。
2. 写下今天最重要的一件事。
3. 给一个项目留下可执行的下一步。
4. 记录一个新发现，或连接一条旧知识。

## 每周十分钟

1. 清理 Inbox：连接、改写、归档或删除。
2. 检查 Projects：继续、暂停、完成。
3. 打开一条旧知识：它本周是否改变了决定？
4. 写下一个意外收获。
5. 选择下周唯一需要保护的结果。

从 `Templates/每周回顾.md` 创建新回顾，或先看[[Review/每周回顾示例|完成示例]]。

## 不追求什么

- 不统计无意义的连续天数。
- 不为了完整填写所有字段。
- 不把首页变成天气、账单、习惯和任务的混合控制台。
- 一周没有新知识并不失败；没有重新使用已有知识才值得检查。
