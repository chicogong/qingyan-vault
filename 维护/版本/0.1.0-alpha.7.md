# Qingyan Vault 0.1.0-alpha.7

这一版完成开源门面与真实连续使用的收尾：不仅首页看起来完整，左侧目录、普通笔记、捕捉编辑、知识总览和仓库 README 也使用同一套产品语言。

## 用户能直接感受到的变化

- 左侧目录增加“收、源、知、事、图、省、AI”语义印记，不改文件夹名称，也不依赖图标插件。
- 普通笔记的标题、章节线、引用、Callout、表格、标签和任务细节统一为青砚视觉。
- 首页动作固定复用实际可见的工作面；捕捉后直接输入，写今天、Bases、Inbox 与项目定位不再跑到隐藏 Leaf。
- GitHub README 先讲一分钟闭环和差异，再展示首页、目录、捕捉、Bases 与深色模式的真实截图。

## 已验证

在全新复制的合成 Vault 与 macOS Obsidian 1.13.7 中逐项完成：

1. 首次插件信任与启用。
2. 动态首页和语义目录明亮主题显示。
3. 捕捉新线索后直接取得编辑焦点并写入中文内容。
4. 回到首页后立即显示新 Inbox 和最近痕迹。
5. 在同一可见工作面打开核心 Bases，并显示新增线索的类型、状态、日期与标签。
6. 对截图、品牌 SVG、目录结构、WikiLinks、隐私标记、第一方插件白名单、无网络调用和发行包运行自动检查。

## 边界

- 所有演示与截图来自合成 Vault，不使用私人知识库。
- 插件不联网、不调用模型、不发送遥测。
- Windows、Linux、移动端与真实用户长期采用仍待验证。
