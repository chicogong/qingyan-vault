# Qingyan Vault 0.1.0-alpha.6

这一版把首页从“看起来能用”推进到真实 Obsidian 工作流可连续完成。

## 修复的真实问题

- 捕捉后不再停在阅读态：新笔记直接进入正文编辑位置并取得键盘焦点。
- 连续点击首页动作不再产生一排标签页：内容统一复用一个工作标签页。
- 项目下一步不再只打开文件：现在会进入编辑态并定位到对应任务。
- 知识总览不再像仓库文件清单：只覆盖 Inbox、Sources、Notes、Projects 与 MOCs。
- 文件名与正文标题不再重复显示；每日笔记不再出现无说明的空任务。

## 已验证

在一个全新解压的发行包与 macOS Obsidian 1.13.7 中，逐项完成：

1. 打开动态首页。
2. 捕捉新线索，无需补点编辑器即可输入，并回读磁盘文件确认内容和元数据。
3. 打开每日笔记，确认复用工作标签页、标题不重复、任务提示清楚。
4. 打开知识总览，确认只包含五个知识生产目录。
5. 全文搜索并命中示例内容。
6. 点击项目下一步，确认打开对应项目并定位任务。

## 边界

- 插件不联网、不调用模型、不发送遥测。
- 只有捕捉动作会新建文件；其他动作只打开或定位本地内容。
- 安全模式下继续使用静态 `Home.md`。
- Windows、Linux、移动端与真实用户长期使用仍待验证。

下载 `qingyan-vault-0.1.0-alpha.6.zip` 后可以运行：

```sh

```
