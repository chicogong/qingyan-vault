# 插件、功能与主题

默认版的原则是：**核心功能开箱即用，社区插件按场景启用，不提供一个难以维护的全家桶。**

## 默认已经配置好的功能

| 中文能力 | Obsidian 核心功能 | 在模板里的入口 |
| --- | --- | --- |
| 全文查找 | 搜索、快速切换 | 首页“我的收件箱”、左侧搜索 |
| 关系导航 | 反向链接、出链、关系图谱 | 右侧栏、知识地图 |
| 结构化信息 | 笔记属性、属性视图 | 每个项目、来源与知识笔记 |
| 数据视图 | Bases | [[知识总览.base|知识总览]]的全部知识、项目、长期知识三种视图 |
| 重复工作 | 模板、每日笔记 | `Templates` 与 `Review/Daily` |
| 空间思考 | Canvas | [[Canvas/夜航花园地图.canvas|夜航花园地图]] |
| 导航与恢复 | 书签、大纲、标签、文件恢复 | 左右侧栏与恢复设置 |

默认关闭同步、发布、网页查看器等联网或公开能力。录音、幻灯片和导入器不属于第一条知识闭环，也保持关闭。

## 你已有的插件资产

现有 `Homepage Enhanced`、`Folder Quick Create`、`Note Agent`、`AI Assistant` 和 `ClaudeTerm` 并没有被忽略。它们分别提供了动态主页、快捷创建、整理预览、AI 对话和侧栏终端，但权限与产品边界不同，不能作为同一个默认插件包发出去。

- 动态主页只吸收最近文件、项目下一步和知识重访，不把天气、习惯、背词等 Personal OS 功能混入 Qingyan Vault。
- Folder Quick Create 是最适合先整理发布的微插件。
- Note Agent 的 Dry Run、日志和人工确认进入 Agent 协议与 Strict Review。
- AI Assistant 与 ClaudeTerm 涉及联网、密钥、索引或 Shell，保留为高级增强，不默认开启。

详细取舍见项目文档 [`docs/PLUGIN_ASSET_REVIEW.md`](../docs/PLUGIN_ASSET_REVIEW.md)。

## 社区插件三档方案

### A｜默认核心版（已交付）

适合第一次使用、公开模板和长期归档。零社区插件；内置一套经过许可审查的静态主题，复制文件夹即可迁移。

### B｜中文效率版（建议按需选择）

| 插件 | 中文体验 | 解决什么问题 | 什么时候值得安装 |
| --- | --- | --- | --- |
| [Editing Toolbar](https://github.com/PKM-er/obsidian-editing-toolbar) | 原生简体中文 | 给不熟 Markdown 的用户一排编辑按钮 | 模板面向大量普通办公用户时 |
| [QuickAdd](https://github.com/chhoumann/quickadd) | 可配置中文命令 | 一键捕捉、按模板创建和选择目标目录 | 捕捉动作每天重复多次时 |
| [Calendar](https://github.com/liamcain/obsidian-calendar-plugin) | 界面简单 | 从月历进入每日笔记 | 日记成为主要入口时 |
| [Tag Wrangler](https://github.com/pjeby/tag-wrangler) | 操作直观 | 批量重命名和整理标签 | 标签规模已经失控时 |
| [Omnisearch](https://github.com/scambier/obsidian-omnisearch) | 支持多语言文本 | 更强的模糊搜索和文档搜索 | 核心搜索召回不足时 |

### C｜自动化研究版（高级）

| 插件 | 能力 | 代价与边界 |
| --- | --- | --- |
| [Dataview](https://github.com/blacksmithgu/obsidian-dataview) | 用属性生成动态列表、表格和任务视图 | 增加查询语言；DataviewJS 可执行 JavaScript。优先试核心 Bases |
| [Tasks](https://github.com/obsidian-tasks-group/obsidian-tasks) | 跨笔记汇总、日期、重复任务和筛选 | 容易把知识库变成第二个任务管理器 |
| [Templater](https://github.com/SilentVoid13/Templater) | 变量、函数、脚本化模板 | 可执行 JavaScript 和系统命令，只用于可信 Vault |
| [Excalidraw](https://github.com/zsviczian/obsidian-excalidraw-plugin) | 绘图、手写、视觉知识卡片 | 体积和学习成本明显上升 |
| Smart Connections / Copilot | 语义检索与 AI 对话 | 涉及模型、网络、密钥和可能的数据外发，默认不纳入 |

## 为什么不照抄热门仪表盘

公开案例常使用 Dataview、Buttons、Tracker、Banners、Iconize、Homepage 等组合，能展示热力图、倒计时、习惯追踪和动态卡片。但它们会让“第一次打开”变成插件安装教程，也会让 GitHub 模板依赖作者持续维护多个第三方项目。

本模板把稳定能力放入核心层，把展示性功能留在可选层。一个功能只有同时满足“改变用户下一步行动”和“维护成本可接受”才进入默认首页。

## Border 底座 + 青砚工作台

默认外观分成两个可替换层：

- `.obsidian/themes/Border/`：MIT 许可的成熟主题底座，负责应用外壳、编辑器排版、浅色与深色模式；原许可与作者声明完整保留。
- `.obsidian/snippets/qingyan-vault.css`：本项目自己的产品层，只负责首页、指南、知识卡片和“青砚工作台”识别语言。

这样既不用从零维护整个 Obsidian 主题，也不会把产品视觉绑死在第三方主题上。若关闭 Border，知识结构仍可用；若关闭项目 CSS，Border 仍提供完整阅读体验。

青砚工作台增强包括：

- 松烟表示内容，砚青表示行动，月白留出阅读空间，朱砂只标人工判断。
- 中文正文使用系统字体，避免下载远程字体；标题保留书卷感。
- 首页只有一个“砚台式行动区”承担强视觉，其他区域保持像一张干净工作纸。
- 首页打开时收起右侧检查区，把宽度还给正在处理的内容；需要时仍可从侧栏按钮打开。
- 支持浅色、深色、窄窗口、键盘焦点和减少动态效果。
- 关闭 CSS 片段后，所有内容、链接、Bases 与 Canvas 仍然有效。

第三方来源与许可见根目录 `THIRD_PARTY_NOTICES.md`。

## 安装社区插件前的门槛

1. 先说明缺少的真实功能，不能只因为案例截图漂亮。
2. 检查官方社区目录、安全评分、维护频率和最近版本。
3. 在合成示例 Vault 试用，不直接对私人知识库试装。
4. AI、同步、Git 类插件必须单独检查联网、密钥和文件权限。
5. 能被核心插件或十行以内本地 CSS 解决的，不增加第三方依赖。
