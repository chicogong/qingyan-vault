# 模板验收清单

无法运行命令行自检时，使用这份清单完成手工验收。

- [ ] 不登录账号，把复制后的文件夹作为新 Vault 打开。
- [ ] 在关闭社区插件时确认 [[Home|首页]] 和 [[开始使用]] 仍可阅读。
- [ ] 确认文件列表不会显示 `.starter-tools` 和 `.github`。
- [ ] 确认同步、发布和网页查看器保持关闭。
- [ ] 确认搜索、反向链接、模板、每日笔记、Canvas、Bases、书签和文件恢复已启用。
- [ ] 完成一次 60 秒完整流程。
- [ ] 切换浅色与深色外观，确认标题、链接、Callout 和搜索结果均清晰可读。
- [ ] 把窗口缩窄到移动端宽度，确认首页仍为单列阅读。
- [ ] 打开 [[白板/夜航花园地图.canvas]]，逐一检查每张文件卡片。
- [ ] 关闭 `qingyan-vault` CSS 片段，确认所有导航仍可用。
- [ ] 确认不存在 `.obsidian/plugins` 目录。
- [ ] 运行 `.starter-tools/self-check.sh`，确认全部通过。
- [ ] 确认 README 截图来自真实 Obsidian，而不是静态渲染器。
