# Agent 工作区

这里保存 Agent 的临时产物和跨会话信息，不属于已经接纳的长期知识。

```text
Agent/
├── 草稿/   生成内容与多文件修改提案
├── 交接/   跨会话、阻塞或明确接力信息
└── 反馈/   可复用的人工纠正
```

## 进入正式知识的门槛

一份 Agent 产物只有同时满足以下条件，才可以由人移动或改写到 `Notes`、`Projects` 或 `MOCs`：

1. 使用过的来源可以追溯。
2. 事实、推断和待验证已经分开。
3. 文件目标和链接关系清楚。
4. 人明确接纳了实际内容，而不只是接纳一句摘要。

详细协议见[[Guides/Agent 使用手册|Agent 使用手册]]。
