# Qingyan Vault 0.1.0-alpha.3

这一版把首页从“展示模板能力”改成真正每天可用的知识工作台。它不再纵向堆叠概念卡片，而是先回答：现在做什么、什么还没完成、一条知识如何成熟、去哪里重新找到它。

## 新变化

- 青砚工作台：砚台式行动区、项目下一步、知识生命周期、Inbox 和知识地图。
- 新视觉：砚青负责行动，松烟承载正文，月白留出空间，朱砂只标人工判断。
- 首页自动释放右侧检查区宽度；移动窄窗口进一步收起左侧文件树。
- 清理 `dist/` 与源码治理文件在日常文件树中的干扰。
- 复盘既有 Homepage Enhanced、Folder Quick Create、Note Agent、AI Assistant 与 ClaudeTerm，形成默认核心版与可选增强包路线。

## 已验证

- macOS、Obsidian 1.13.7：浅色和深色首页真实渲染通过。
- 首页行动链接、核心搜索、项目任务查询、WikiLinks 与 Bases 入口可见。
- 源码自检、隐私扫描、确定性打包、二次解压自检与 GitHub Actions。
- Release ZIP 保持零社区插件、零凭据、零机器绝对路径。

## 已知边界

- 动态“最近文件”和“知识重访”尚未默认启用；计划由最小 `Qingyan Home` 可选插件承担。
- Windows、Linux、iOS 和 Android 尚未做真实 UI 回归。
- 既有插件只完成资产与权限复盘，没有把未经重构的旧代码直接打包进公开模板。

升级前请备份已有 Vault。下载 `qingyan-vault-0.1.0-alpha.3.zip` 后可运行：

```sh
sh ./.starter-tools/self-check.sh
```
