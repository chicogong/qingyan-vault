# Qingyan Vault 0.1.0-alpha.1

首个公开 Alpha：开箱即用、中文优先、人与 Agent 共用且由人定稿的本地 Obsidian Vault。

## 本次包含

- 首页、Inbox、Sources、Notes、Projects、MOCs、Review、Templates、Bases 与 Canvas 的完整合成知识链。
- 浅色/深色 Qingyan 视觉层与 MIT Border 主题。
- `AGENTS.md`、Claude 适配、R0 只读、R1 隔离草稿、交接与反馈约定。
- 可选 LLM Wiki Canvas Strict Review 手册。
- 双语 README、隐私/许可检查、CI、Issue 模板和可复现发行包。

## 已验证

- macOS、Obsidian 1.13.7：首次注册 Vault 后自动打开 `Home.md`。
- 浅色和深色真实界面：首页、查询、WikiLinks 和导航可见。
- 源码自检与 Release ZIP 二次解压自检通过。
- 默认无社区插件、无网络插件、无凭据特征、无机器绝对路径、示例来源均标记为合成。
- LLM Wiki Canvas 0.2.0：正常建议可以审核并接纳；审核后目标变化会阻断旧建议应用。

## 已知边界

- Windows、Linux、iOS 与 Android 尚未做真实界面验收。
- WorkBuddy、Claude Code 等宿主的真实运行不在首发通过项；文件协议已经提供，但不能用静态检查冒充真实执行。
- LWC 0.2.0 的知识图 Lint 尚不识别 Obsidian `.base`、`.canvas` 和表格内转义 WikiLink；这不影响 Proposal Strict Review，也不代表对应 Obsidian 链接失效。
- Alpha 可能调整模板和配置；升级前请备份自己的 Vault，不要覆盖现有文件。

## 文件校验

发布页附带 `qingyan-vault-0.1.0-alpha.1.zip`。下载后可以运行：

```sh
sh ./.starter-tools/self-check.sh
```
