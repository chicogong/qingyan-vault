# Qingyan Vault 0.1.0-alpha.2

首个推荐下载的公开 Alpha。它包含 `alpha.1` 的全部能力，并修正真实 Obsidian 打开后发现的工作区最近文件污染。

## 已验证

- macOS、Obsidian 1.13.7：首次打开指向 `Home.md`，浅色和深色界面通过。
- 源码检查、确定性打包、二次解压检查和 GitHub Actions 通过。
- Release ZIP 不含 `.git/`、社区插件、同步状态、源码治理文件、凭据或机器绝对路径。
- 工作区不引用 `dist/`、`docs/`、`.github/` 或临时文件。
- LLM Wiki Canvas 0.2.0：正常建议可审核接纳；目标在审核后改变时旧建议被阻断。

## 已知边界

- Windows、Linux、iOS、Android 和非 Codex Agent 宿主尚未做真实执行验收。
- LWC 0.2.0 的知识图 Lint 尚不识别 Obsidian `.base`、`.canvas` 和表格内转义 WikiLink；不影响 Proposal Strict Review。
- Alpha 升级前请备份自己的 Vault，不要直接覆盖已有笔记。

下载 `qingyan-vault-0.1.0-alpha.2.zip` 后可以运行：

```sh
sh ./.starter-tools/self-check.sh
```
