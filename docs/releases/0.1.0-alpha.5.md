# Qingyan Vault 0.1.0-alpha.5

这一版不增加功能，集中修正首页的视觉完成度和内容层级。

## 新首页

- 移除绿色大卡片、四块统计卡和压缩工具栏式布局。
- 使用冷月白纸面、松烟正文、砚青宣言、青玉连接与朱砂动作建立 Qingyan 专属视觉语言。
- 右侧“砚池宣言”成为唯一强视觉：人决定什么值得留下，Agent 帮你整理来路。
- 四个常用动作改成两列印章式入口；“知识水路”用真实流程连接收进来、想清楚和用起来。
- 项目下一步、最近痕迹、Inbox 与知识重访改为编辑式细线列表，不再呈现成通用 SaaS 卡片。

## 已验证

- macOS + Obsidian 1.13.7 真实渲染。
- 浅色、深色、宽屏与窄内容面板。
- 左侧栏展开/收起与内容面板级响应式布局。
- 首页滚动、项目与最近编辑列表、四个既有动作的可访问名称。
- 静态 `Home.md` 降级、自检、确定性发行包和解压复检。

## 没有改变的边界

- 插件仍然不联网、不调用模型、不发送遥测。
- 只有点击“捕捉线索”时才向 `Inbox/` 写入文件。
- 安全模式下继续使用静态 `Home.md`。
- Windows、Linux、移动端与真实用户长期使用仍待验证。

下载 `qingyan-vault-0.1.0-alpha.5.zip` 后可以运行：

```sh
./.starter-tools/self-check.sh
```
