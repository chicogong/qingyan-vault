# Qingyan Vault 0.1.0-alpha.4

> 已由 `0.1.0-alpha.5` 取代。`alpha.5` 保留动态能力并重做了完整视觉系统。

这是修正产品身份并交付真正动态首页的 Alpha 版本。

## 本轮交付

- 产品名统一为 `Qingyan Vault`，解释为 `Agent-native Obsidian Vault`。
- 第一方 `Qingyan Vault Homepage` 以独立 Obsidian View 呈现，不再把静态 Markdown 首页冒充动态产品。
- 首页实时读取用户内容区，提供时间与问候、快速捕捉、每日笔记、搜索、Bases、最近编辑、Inbox、项目下一步与知识重访。
- 插件不联网、不调用模型、不读取凭据、不建立向量索引、不发送遥测；只有点击“捕捉线索”时写入 `Inbox/`。
- 关闭插件或使用安全模式时，静态 `Home.md`、Markdown、WikiLinks、Bases 与 Canvas 仍可使用。

## 已验证

- macOS + Obsidian 1.13.7 真实打开。
- 浅色与深色动态首页。
- 搜索、知识总览、捕捉线索与每日笔记入口。
- 静态首页降级。
- 仓库自检、发行包解压复检与插件白名单/无网络调用检查。

## 首次打开

Obsidian 会把随 Vault 分发的可执行代码视为社区插件，因此会显示标准信任提示。只从本仓库 Release 下载后选择“信任仓库作者并启用插件”。若暂不启用，选择安全模式即可使用静态首页。

## 边界

- Windows、Linux、移动端与其他 Obsidian 版本待验证。
- 当前没有真实用户留存或自然复用证据。
- 不内置聊天、模型、向量数据库、同步或 Shell。

升级前请备份已有 Vault。下载 `qingyan-vault-0.1.0-alpha.4.zip` 后可以运行：

```sh
./.starter-tools/self-check.sh
```
